# ポイントシステム 仕様書

## 1. 概要

キャンパスフェスティバル向けのポイントシステム。来場者は展示ゲームやブースをクリアすることでポイントを獲得し、景品交換やカジノ系ブースで消費できる。

- **開催期間**: 1日
- **想定参加者数**: 数百人
- **運用形態**: 自前サーバーでの運用（Docker Compose）

## 2. 登場するロール

| ロール | 説明 | 認証方法 |
|---|---|---|
| ユーザー | 来場者。ポイントを獲得・消費する | 発行されたQRコードを読み取ってログイン |
| スタッフ | ブース製作者・景品交換担当。ポイントの付与/消費操作を行う | 発行されたQRコードを読み取ってログイン |
| 管理者 | システム全体の管理者 | 発行されたワンタイムトークンを入力してログイン |

- ユーザーは**自分でアカウントを作成できない**。運営が発行した信頼できるアカウントのみが存在する。
- スタッフは**特定のブースに紐づく**。自分のブース以外の操作はできない。

## 3. アカウント発行とログイン

### 3.1 ユーザー

1. 会場入り口の端末で、スタッフがユーザー用アカウントを発行する
2. 入り口端末の画面に、短時間で失効し、初回ログイン成功後に無効化されるログイン用QRコードを表示する
3. ユーザーが自身のスマートフォンでQRコードを読み取る
4. ポイントシステムのWebページに遷移し、ログインが完了する
5. 初回ログイン時に、ユーザーが**表示名**を自由に入力する

- セッションはイベント終了まで有効

### 3.2 スタッフ

- 管理者がスタッフアカウントを発行し、ログイン用QRコードを発行する
- 担当ブースはスタッフアカウントの作成後に割り当てる
- スタッフはQRコードを読み取ってログインする
- アカウントには担当ブースが紐づけられる

### 3.3 管理者

- 管理者は、発行されたワンタイムトークンをログイン画面に入力してログインする
- ログイントークンは短時間で失効し、初回ログイン成功後に無効化される
- ログイントークン自体にはロールを含めず、トークンに紐づくアカウントのロールをデータベースから取得する
- 最初の管理者アカウントは、`npm run admin:create`（Docker環境では `docker compose exec backend npm run admin:create`）で作成し、ログイントークンを発行する
- 2人目以降の管理者アカウントとログイントークンは、ログイン済みの管理者が管理画面から発行する

## 4. ユーザー画面

表示する情報:

- 現在のポイント残高
- 動的QRコード（本人識別用）
- 表示名

### 4.1 動的QRコード

- ユーザーを識別するためのQRコードを画面に表示する
- 一定時間ごとに自動で更新される（ワンタイム方式）
- 目的: スクリーンショットの使い回しなどによる不正防止

## 5. ポイント付与

### 5.1 展示ブースでの付与

- ゲーム製作者がブースに常駐し、**製作者の端末**を使って操作する
- ゲーム本体にQR読み取り機能などを組み込まない方針
- フロー:
  1. ユーザーがゲームをクリアする
  2. ユーザーが自分の画面の動的QRコードをスタッフに提示する
  3. スタッフが端末でQRコードを読み取る
  4. ポイントが付与される

### 5.2 付与ポイント数

- ブースごとの**固定値**（スタッフが任意の数値を入力することはできない）

## 6. ポイント消費

### 6.1 景品交換

「コンビニのレジ」に近いフロー:

1. ユーザーが景品を自由に手に取る
2. スタッフに提示する
3. スタッフが必要ポイント数を確認する
4. ユーザーが動的QRコードをスタッフに提示する
5. スタッフが端末で読み取り、ポイントを消費する

### 6.2 カジノ系ブース

- **ユーザー自身が画面上で操作**してポイントを消費する
- 不正防止のための追加確認（スタッフの目視確認・確認コード等）は行わない

## 7. ランキング

- 会場内の**モニターに表示**する用途
- ユーザー個人の画面には表示しない

## 8. 管理画面

必要最低限の機能を備える:

- ユーザーアカウントの発行
- スタッフアカウントの発行（担当ブースの紐づけ）
- 管理者アカウントの発行
- ブースの登録・付与ポイント数の設定
- ポイント付与/消費状況の確認
- ランキング表示

## 9. 技術スタック

| 領域 | 技術 |
|---|---|
| バックエンド | Hono |
| フロントエンド | React + Vite |
| スタイリング | Tailwind CSS |
| データベース | PostgreSQL |
| 実行環境 | Docker Compose |
| ホスティング | 自前サーバー |
